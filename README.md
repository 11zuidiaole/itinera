# itinera

一个主要在手机上用的日程网页，有月、周、日三种视图。可以手动加活动，也可以把备忘录文字或者携程截图粘进来，自动整理成日程。

网址：https://11zuidiaole.github.io/itinera/

用 iPhone Safari 打开后，点分享 →“添加到主屏幕”，就能像 App 一样打开。

---

## 功能

### 三种视图
- **月**：每天显示活动名字，一天最多显示 3 个，多的显示成“+N”。点某一天会进入日视图
- **周**：有时间轴（6:00–24:00，每 3 小时一条线），有时间的活动按时间显示成色块；没有时间的活动放在顶部的“待定”一行
- **日**：分成“待定”和“安排”两组，“安排”按时间排序

月视图里的显示顺序：置顶 > 飞机 > 有时间的 > 待定。

### 切换和翻页
- 左右滑：上一页 / 下一页
- 双指张开：月 → 周 → 日（手指放在哪天就跳到哪天）
- 双指捏合：日 → 周 → 月
- 点“今天”：弹出前天 / 昨天 / 今天 / 明天 / 后天，选“今天”以外的会直接跳到那天的日视图

### 新建和编辑活动
- 右下角“+”新建，或者在周视图里点空白的时间格
- 时间都是可选的：开始、结束都设 / 只设开始（显示 `19:45~`）/ 只设结束（显示 `~18:00`）/ 都不设
- 都不设的时候可以选“上午 / 下午 / 晚上”
- 时间先选几点，再选分钟（00 / 15 / 30 / 45），分钟不选默认 00
- 日期下面有“今天 / 明天 / 后天”快捷按钮
- 颜色默认“自动”：同名活动沿用之前的颜色，其他的优先选当天还没用过的颜色
- 可以置顶（pin）

### 常用活动
都在新建活动页面最上面的“常用”里：
- 点一下就自动填好名字和颜色；设了时长的，选好开始时间会自动算出结束时间
- 点右边的**编辑**：在“＋ 添加”里直接输入名字新建；拖动调整顺序；点一下在下面直接改名字、颜色和时长；点 × 删除（可以撤销）
- 新加常用时，如果活动名称还空着，会自动填上
- 新建活动时也可以勾“存为常用”

### 手势（日视图）
- 左滑一项：出现删除
- 长按“待定”里的一项：可以拖动换顺序，拖到屏幕底部松手就删除
- 弹出的页面（新建、设置等）可以往下滑关掉

### 交通图标和班次号
名称或备注里有这些词会自动加图标：
- 飞机：飞机、航班、登机、起飞，或者名字以“飞”开头
- 火车：高铁、动车、火车、列车
- 出租车：打车、出租、滴滴、Uber
- 汽车：开车、自驾
- 床：入住、退房、住宿、酒店、民宿

写了航班号（CA1234、MU5101）或车次（G102、D312）的，周视图和日视图会自动显示出来。

## 粘贴行程（右上角备忘录图标）

有两种整理方式：

**1. 登录后：交给 Claude 整理**
- 可以粘贴文字，也可以选截图（最多 8 张）
- 携程订单、攻略表格、随手写的备忘录都能识别
- 需要先在设置里登录，并且后台函数已经部署好（见下面“后台设置”）

**2. 没登录：用本地规则整理**
只能识别文字，能认出：
- 日期：今天、明天、后天、周三、下周一、11.15、11/15、11月15日、12号；单独一行的日期会管下面所有行
- 时间：3点、下午3点、7点半、7:45、10点-12点、晚上7点半到9点、9点前
- 时段小标题：“上午：”“下午”“晚上：”会管下面几行
- 饭点：晚饭 7:45 → 19:45，午饭 1点 → 13:00
- 缩进的子项会合并到上一项的备注里
- 备忘录的勾选框【】、[ ]、○ 会自动去掉
- 携程航班、酒店卡片（用 iPhone 长按截图拷贝文字后粘贴）

不管哪种方式，加入前都会先列出来让你确认，不要的可以取消勾选。

## 数据和同步

- 没登录：数据只存在这台设备的浏览器里，换设备或者清除浏览器数据就没了
- 登录后：自动同步到 Supabase，换设备登录同一个账号就能看到
- 账号和 deadline catcher 是同一个
- 每 10 分钟最多自动存一个历史版本，在“设置 → 历史版本”里可以恢复
- 第一次登录时，如果这台设备和账号里都有内容，会问你用哪一份，另一份存进历史版本

## 后台设置

用的是 deadline catcher 那个 Supabase 项目，另外建了两张表，数据互不影响。

### 1. 建表
在 Supabase → SQL Editor 里运行 `supabase.sql` 的全部内容。会建这两张表：
- `itinera_boards`：每个用户一行，存全部日程
- `itinera_history`：历史版本，每人保留最近 200 份

### 2. 部署截图识别的后台函数
1. Supabase → Edge Functions → Deploy a new function → Via Editor
2. 函数名填 `itinera-ai`
3. 代码换成 `supabase/functions/itinera-ai/index.ts` 的全部内容
4. Deploy

以后改了这个文件，要在 Supabase 里打开 itinera-ai → Code，换成新代码，再点 Deploy updates。

### 3. 填 Secrets
Edge Functions → Secrets，加两条：

| Name | Value |
|---|---|
| `ANTHROPIC_API_KEY` | Claude Console 里建的 API key |
| `ALLOWED_EMAILS` | 允许使用的邮箱，多个用逗号隔开 |

`ALLOWED_EMAILS` 一定要填。不填的话，任何人在网页上注册一个账号就能用你的额度。想给朋友用，就把他们的邮箱加进去。

### 费用
- 用的是 Claude Haiku 5.5，一张截图大概不到 1 美分
- Claude Console 里关了自动充值，设了每月 5 美元的花费上限，超了会自动停，不会多扣钱
- API key 如果设了有效期，到期后识别就会失效（有效期 14 天以上的 key 会提前 7 天发邮件提醒）。到时候在 Claude Console 建一个新的，替换 `ANTHROPIC_API_KEY` 就行
